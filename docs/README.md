# Cognibrain Documentation

Cognibrain is a self-hosted engineering memory layer for coding agents. The CLI is the operator surface, MCP is the agent surface, and SDK/HTTP is the extension surface for custom products and community adapters.

## Product Snapshot

Cognibrain records durable engineering memory: repo rules, user corrections, action guards, connector events, evidence packs, patch evidence, release outcomes and maintenance signals. Agents can ask for compact context before they act; operators can inspect and manage the runtime from a stable operator CLI.

## Claim Boundary

The docs describe the current open-source self-hosted repository. Generated benchmark, connector and truth reports are internal CI/build outputs under `artifacts/`. They are useful for review, but they are not shipped as source documentation or used as standalone proof without the code and commands that generated them.

Managed SaaS uptime, billing, hosted support, autoscaling and deployment-specific enterprise rollout are not current repository claims.
