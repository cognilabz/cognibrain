# Repo-Wide Shared Working Memory

Cognibrain will make Ephemeral Working Memory visible across capable agents in the same repository, not only agents participating in the same task. This supports the Mistake Prevention Claim: once Cognibrain observes an active mistake or task-local failure signal, other repo agents should be able to avoid repeating it even before the signal is promoted into durable memory.

Repo-wide sharing does not make working memory durable or trusted. Shared Working Memory remains outside the Memory Ledger unless a Judgment Request and Promotion Event make it safe to retain.
