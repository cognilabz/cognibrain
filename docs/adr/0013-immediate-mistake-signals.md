# Immediate Mistake Signals

Cognibrain will create a repo-wide Mistake Signal in Shared Working Memory as soon as it observes, is corrected about, or predicts an agent mistake. This supports the Mistake Prevention Claim by warning other capable agents immediately, while preserving the durable-memory boundary: a Mistake Signal still needs a Judgment Request and Promotion Event before it becomes trusted memory or an Action Guard.

Mistake Signals must distinguish confirmed and predicted cases. A Confirmed Mistake Signal comes from an observed failure or explicit correction; a Predicted Mistake Signal is a tentative pre-execution warning that should prevent likely repeat mistakes without pretending the failure has already happened.
