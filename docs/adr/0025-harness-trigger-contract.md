# Harness Trigger Contract

Cognibrain will require every supported Harness to implement the same Harness Trigger Contract, even when adapters differ for Codex, Copilot, Claude, Hermes, or other agents. A harness is supported only when Harness Conformance proves it triggers the Brain Lifecycle at required workflow moments, including session start, before action, after tool result, after user correction, before final answer, after task outcome, and session end.
