# One-Time Harness Certification

Cognibrain treats Certified Harness status as persistent after the first successful Harness Conformance run. Certification does not automatically expire, demote to Best-Effort Harness, or enter a review-required state when the harness package, Harness Trigger Contract, or host workflow changes. This favors stable product language and low integration friction over freshness-scoped certification; any future freshness signal must be named separately from Certified Harness.
