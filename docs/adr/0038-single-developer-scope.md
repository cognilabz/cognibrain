# Single Developer Scope

Status: superseded by ADR-0061.

Cognibrain is scoped to a single developer, not teams, workspaces, organizations, or tenants. Memory, harness behavior, Signal Noise Thresholds, and operator surfaces should be designed around one developer managing repo-scoped memory across their own capable agents. This keeps the product focused on preventing one developer's agents from repeating known mistakes instead of drifting into collaboration and account-management features.
