# Harness-Native Operator Experience For The Greenfield Rebuild

The greenfield memory solution has no Operator UI or commercial dashboard product surface. This is not an instruction to delete the existing solution's legacy dashboard code or historical docs; it only means the rebuilt solution should not include that surface. Operator-facing work belongs in harness-native prompts, Action Guards, and the text-first CLI, because the memory product must act at the moment agents work instead of requiring a separate dashboard habit.
