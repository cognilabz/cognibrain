# Benchmark Methodology

Benchmarks are split by claim type.

| Suite | Purpose | Claim boundary |
| --- | --- | --- |
| CogniCodeBench | Synthetic coding-agent correction carryover | Does not prove real customer repo performance |
| Nextgen suites | Memory OS behavior, evidence, graph, temporal and lifecycle surfaces | Local checkout proof |
| Connector verifiers | Harness and vendor-driver compatibility | Tenant certification requires credentials |
| Postgres verifier | Self-hosted storage behavior | Target database must rerun it |
| Load benchmark | Local scale and latency profile | Hardware and storage dependent |

Claim IDs: `CB-CLAIM-COGNICODE`, `CB-CLAIM-ABLATION`, `CB-CLAIM-PRODUCTION`.
