# cognibrain vs Hindsight

## Best For

Hindsight-style platforms are best for general production agent memory infrastructure, observations and mental-model style retrieval.

## Where cognibrain Differs

cognibrain specializes in software engineering loops: review correction, tool outcome, forbidden action, procedure recall, codebase migration and patch evidence.

Claim IDs: `CB-CLAIM-CONTEXT`, `CB-CLAIM-PATCH-EVIDENCE`, `CB-CLAIM-GUARD`.

| Area | General agent memory | cognibrain |
| --- | --- | --- |
| Core loop | Observe and retrieve | Correction -> memory -> next patch |
| Evidence | Platform-dependent | EvidencePack and Patch Evidence Trail |
| Coding specificity | General | Engineering Memory kinds and codebase scope |
| Benchmark | General memory behavior | CogniCodeBench synthetic coding-agent loop |
| Deployment | Product-dependent | Local-first self-hosted candidate |

## Benchmark Boundary

cognibrain's public proof is coding-agent-specific and synthetic. It should be compared to Hindsight only through equivalent tasks and metrics.

Claim IDs: `CB-CLAIM-COGNICODE`, `CB-CLAIM-MARKET`.

## Honest Limitations

cognibrain does not claim the broadest production agent-memory infrastructure footprint. It intentionally starts with engineering behavior.

## CTA

Inspect a patch trail before choosing: the differentiator is whether memory explains the next code change.
