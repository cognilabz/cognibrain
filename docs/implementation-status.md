Latest CogniCodeBench proof: `npm run benchmark:cognicode` generated 100 deterministic synthetic repository scenarios across TypeScript/Node, Python/FastAPI, Go, React, monorepo, and legacy-repo layouts, wrote `artifacts/cognicodebench/scenarios.json` and `artifacts/cognicodebench/run.json`, passed all simulator checks, and reported correction carryover `1`, repeated mistake rate `0`, procedure recall `1`, patch correctness `1`, evidence completeness `1`, and wrong-memory suppression `1`. This is synthetic Engineering Memory proof, not proof that arbitrary real customer repositories or live coding agents will achieve the same rates. The leaderboard now includes an `engineering_memory` entry from the CogniCodeBench artifact.

Latest Postgres proof: `npm run verify:postgres` starts or reuses a local Postgres 16 container, applies idempotent migrations, writes real rows into tenant-indexed tables, uses a generated `tsvector` plus GIN index for lexical retrieval, checks cross-user isolation, and writes `artifacts/postgres-live.json`. The 2026-05-25 run passed all acceptance checks with 25 writes, 10 searches, zero failures, migration count `3 -> 3`, write p95 `60.86ms`, search p95 `118.29ms`, `aliceAtlasRows=1`, `bobAtlasRows=0`, and `bobSearchLeaks=0`.
