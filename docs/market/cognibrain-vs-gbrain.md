# cognibrain vs GBrain

GBrain is best understood as a markdown-first personal or operator brain. cognibrain is aimed at API-first engineering memory for coding agents and teams.

## Where cognibrain is different

- It exposes HTTP, MCP, SDK, CLI, dashboard, connector, and harness surfaces from the same memory engine.
- It models team/project/org/agent/source scope and policy checks for retrieval.
- It records tool outcomes, review corrections, and patch evidence as product primitives.
- It publishes benchmark artifacts rather than relying only on note quality or backlink structure.

## Claim Boundary

This comparison should stay focused on integration surface, team scope, and coding-agent evidence. It should not claim superiority for personal note-taking workflows without a comparable evaluation.
