# cognibrain vs Hindsight

Hindsight is an agent memory infrastructure reference point with public BEAM-facing market material. cognibrain's strongest product story is narrower: evidence-grade engineering memory for coding agents.

## Where cognibrain is different

- It separates public benchmark gates from Engineering Memory OS proof through CogniCodeBench.
- It keeps claim boundaries explicit through `docs/claims.md`, `docs/implementation-status.md`, and market-gate artifacts.
- It exposes coding-specific memory capture and action guard surfaces through API, MCP, SDK, and harness hooks.
