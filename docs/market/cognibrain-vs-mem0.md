# cognibrain vs Mem0

Mem0 is a strong general-purpose memory layer with broad distribution and public benchmark material. cognibrain should not be described as "Mem0 plus more features"; the sharper comparison is use-case scope.

## Where cognibrain is different

- Engineering Memory types are first class: repo policies, architecture decisions, review corrections, tool outcomes, procedures, forbidden actions, migrations, test strategies, dependency rules, and generated-file rules.
- CogniCodeBench measures whether a coding agent applies corrections on the next code change.
- Evidence packs, action guards, and patch evidence trails expose why a memory was used during an engineering task.
- Harness and connector surfaces focus on coding agents, reviews, CI, and tool outcomes.

## Claim Boundary

Use this page as a claim boundary, not a leadership claim. Direct benchmark comparison requires imported Mem0 artifacts with the same CogniCodeBench schema or the same public benchmark dataset, metric, top-K or token budget, and per-question rows.
