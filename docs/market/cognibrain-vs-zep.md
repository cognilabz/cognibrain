# cognibrain vs Zep

Zep is strong in conversational and temporal graph memory. cognibrain uses graph and temporal evidence too, but its wedge is engineering workflows.

## Where cognibrain is different

- Codebase scope covers repo, branch, commit, package, directory, file pattern, language, framework, and harness context.
- Temporal belief revision is tied to codebase evolution such as test migrations, deprecated APIs, generated-file workflows, and directory conventions.
- Patch evidence trails show which memories, procedures, corrections, commands, graph paths, and stale exclusions affected a code change.

## Claim Boundary

This is a category-positioning page. Direct Zep comparison needs comparable artifacts with matching dataset, metric, top-K or budget, and audit rows.
