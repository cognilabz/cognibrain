# CogniCodeBench Proof

CogniCodeBench exists because generic memory recall does not show whether a coding agent avoids a corrected engineering mistake.

It measures correction carryover, repeated mistake rate, procedure recall, patch correctness, evidence completeness and wrong-memory suppression across deterministic synthetic repo scenarios.

This is synthetic proof, not a real customer-repository performance claim.

Claim IDs: `CB-CLAIM-COGNICODE`, `CB-CLAIM-ABLATION`.
