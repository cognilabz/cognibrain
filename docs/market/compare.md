# Table-First Comparisons

Textual compare pages are not strong enough for engineering-memory claims. Every public comparison should start with a generated proof table, then explain fit and gaps.

## Pattern

| Section | Rule |
| --- | --- |
| Proof table | First section after the title. Use the latest Benchmark Arena artifact. |
| When to choose competitor | State the honest competitor fit. |
| When to choose Cognibrain | Tie to engineering corrections, action guards, connector events and patch evidence. |
| Capability gaps | Use declared gaps from the adapter report, not invented copy. |
| Reproduce | Include the command and artifact path. |

## Core Copy

Recall is not enough. The next code change has to prove the memory worked.

A memory system that cannot prevent repeated mistakes is just searchable history.

We do not ask whether the agent can remember. We test whether it changes future behavior.

## Repro Command

```bash
npm run benchmark:arena
npm run benchmark:arena:publish
```
