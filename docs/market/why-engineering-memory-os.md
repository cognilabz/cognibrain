# Why Engineering Memory OS

Coding agents do not only need memory. They need engineering memory: scoped rules, review corrections, command outcomes, procedures, generated-file boundaries and migration validity.

cognibrain packages those signals into an inspectable operating layer: MemoryRecordV2, EvidencePack, coding context pack, action guard, patch evidence, policy gates and lifecycle maintenance.

Claim IDs: `CB-CLAIM-CONTEXT`, `CB-CLAIM-EVIDENCE`, `CB-CLAIM-PATCH-EVIDENCE`.
