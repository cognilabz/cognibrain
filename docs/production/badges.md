# Production Boundary Badges

Use these labels in status docs, release notes and issue triage.

| Badge | Meaning |
| --- | --- |
| `local-ready` | Works in local checkout or package install. |
| `self-hosted candidate` | Has code and docs for team deployment after target gates. |
| `deployment-verified` | A specific target environment has fresh passing artifacts. |
| `vendor-smoke required` | Tenant connector credentials must be tested. |
| `managed SaaS future` | Not part of the current self-hosted release claim. |

Claim IDs: `CB-CLAIM-STATUS`, `CB-CLAIM-PRODUCTION`.
