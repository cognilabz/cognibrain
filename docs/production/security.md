# Security

## Controls

- API keys for networked deployments.
- TLS termination through HTTPS or `MEMORY_TLS_TERMINATED_BY`.
- Secret redaction or encryption for sensitive memory writes.
- Connector auth references instead of plaintext tokens.
- Policy rules for retrieve/write/export/delete boundaries.
- Audit chain for memory lifecycle and policy events.

## Non-Claims

This repo does not claim managed SaaS SOC2, hosted support, uptime SLA, billing security, or tenant SSO certification.
