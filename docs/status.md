# Status

The live status surface is [`implementation-status.md`](implementation-status.md).

Use this short page as the stable docs entry point for release notes, websites and launch copy.

## Maturity Labels

- `local-ready`: works in a local checkout or npm install with documented setup.
- `self-hosted candidate`: can be run by a team after auth, durable storage, backup and transport controls are configured.
- `deployment-verified`: requires a fresh target-environment artifact.
- `vendor-smoke required`: connector-specific credentials must be tested for the tenant.
- `managed SaaS future`: not a current release claim.

Claim IDs: `CB-CLAIM-STATUS`, `CB-CLAIM-PRODUCTION`.
